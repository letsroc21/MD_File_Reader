# Welcome

This is a sample Markdown file you can open in **MD File Reader**.

## What you can do

- Open `.md` files and read them as rendered pages
- Switch to **Edit** for a word-processor-style writing view
- Create a new file, write, and save it back as Markdown

## A small example

1. Click **New**
2. Write a heading and a few paragraphs
3. Press **Save**

> Reading should feel like opening a document, not an IDE.
